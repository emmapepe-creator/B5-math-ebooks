💡 連比例式的拆解筆記
❶ a : b ＝ 2 : 3 ⇒ 3a ＝ 2b 或 a / 2 ＝ b / 3
❷ a : b : c ＝ 2 : 3 : 4 ⇒ 可拆解為三個「兩兩比」關係：
❸ a : b ＝ 2 : 3； b : c ＝ 3 : 4； a : c ＝ 2 : 4 ＝ 1 : 2

概念 ❸a : b : c ＝ 2 : 3 : 4 的意義
份數觀念與設 r 代數化
☆ a : b : c ＝ 2 : 3 : 4 是什麼意思？
❶ a 一定是 2，b 一定是 3，c 一定是 4 嗎？不一定
❷ a 是 2 份，b 是 3 份，c 是 4 份。
❸ 假設 a ＝ 2r，b ＝ 3r，c ＝ 4r（其中 r ≠ 0）
☆ 還有沒有其他的表示方法？
a : b : c ＝ 2 : 3 : 4 ⇒ a : 2 ＝ b : 3 ＝ c : 4
⇒ a / 2 ＝ b / 3 ＝ c / 4
⇒ a ＝ 2r，b ＝ 3r，c ＝ 4r
☆ 觀念筆記思考題
• a : b : c ＝ 2 : 3 : 4，請問 a, b, c 誰最大？
答：c 最大
• 2a : 3b ＝ 4 : 9，請問 a : b ＝ ？
答：2 : 3
整理：a : b : c ＝ 2 : 3 : 4
⇒ a / 2 ＝ b / 3 ＝ c / 4
⇒ a＝2r, b＝3r, c＝4r (r ≠ 0)
牛刀小試 ❸代數假設與分式轉連比
1. 若 a : b : c ＝ 1 : 3 : 5
(1) a : 1 ＝ b : 3 ＝ c : 5
(2) a / 1 ＝ b / 3 ＝ c / 5
(3) 表示 a 是 1 份，b 是 3 份，c 是 5 份。
(4) 假設 1 份是 r (r ≠ 0)，a ＝ r，b ＝ 3r，c ＝ 5r。
2. 若 a : b : c ＝ 3 : 4 : 5
(1) a : 3 ＝ b : 4 ＝ c : 5
(2) a / 3 ＝ b / 4 ＝ c / 5
(3) 表示 a 是 3 份，b 是 4 份，c 是 5 份。
(4) 假設 1 份是 r (r ≠ 0)，a ＝ 3r，b ＝ 4r，c ＝ 5r。
3. 比例連等轉連比
(1) 若 a : 5 ＝ b : 7 ＝ c : 6，則 a : b : c ＝ 5 : 7 : 6
(2) 若 a : 2 ＝ b : 3 ＝ c : 5，則 a : b : c ＝ 2 : 3 : 5
4. 分式連等轉連比
(1) 若 a / 4 ＝ b / 5 ＝ c / 6，則 a : b : c ＝ 4 : 5 : 6
(2) 若 a / 3 ＝ b / 7 ＝ c / 9，則 a : b : c ＝ 3 : 7 : 9
5. 係數連比化簡
(1) 3a : 4b : c ＝ 9 : 8 : 1，則 a : b : c ＝ 3 : 2 : 1
(2) 5a : b : 2c ＝ 10 : 3 : 8，則 a : b : c ＝ 2 : 3 : 4

(1) 3a : 4b : 5c ＝ 3 : 6 : 10
＝ 設 a＝2r, b＝3r, c＝4r (r ≠ 0)
＝ 3(2r) : 4(3r) : 5(4r) ＝ 6r : 12r : 20r

(2) (a + b) : (b + c) : (c + a) ＝ 5 : 7 : 6
＝ (2r + 3r) : (3r + 4r) : (4r + 2r)
＝ 5r : 7r : 6r ＝ 5 : 7 : 6

逐步點擊揭曉解題算式
皓柔、珮瑜、苡安都喜歡動漫，他們一起出錢買了一個 1200 元的公仔，已知三人出錢的比為 3 : 4 : 5，則三人分別出了多少錢？
答：皓柔出 300 元，珮瑜出 400 元，苡安出 500 元
＝ 設三人出錢分別為 3r、4r、5r 元 (r > 0)
＝ 3r + 4r + 5r ＝ 1200 ⇒ 12r ＝ 1200 ⇒ r ＝ 100
＝ 3 × 100 ＝ 300，4 × 100 ＝ 400，5 × 100 ＝ 500
